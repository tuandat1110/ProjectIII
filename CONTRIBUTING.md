# Contributing to ProjectIII

Thanks for your interest in contributing! To make the process smooth:

- Fork the repository and create a feature branch: `git checkout -b feature/your-feature`
- Keep changes small and focused. One PR per feature/bugfix.
- Write unit tests for new features and run existing tests.
- Follow existing code style. Run linters before submitting.
- Use descriptive commit messages and reference issues when appropriate.
- Ensure CI passes before requesting a review.

Code review checklist:
- Does the PR include tests or a rationale for missing tests?
- Are new dependencies necessary and reviewed?
- Is sensitive data (secrets/keys) excluded from the commit?

Thank you!
